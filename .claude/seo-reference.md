## 3. Структура папок

```
CLAUDE.md            ← этот файл, главные правила
docs/                ← подробные методики, читаются по необходимости
templates/           ← шаблоны документов и CSV
.claude/commands/    ← свои команды под RU-специфику
.claude/skills/      ← свои скиллы (seo-crawl)
projects/<клиент>/   ← вся работа по клиенту
    project-profile.md   карточка проекта — читается первой
    data/                сырые выгрузки: краулы, GSC, Wordstat, SERP
    work/                черновики, промежуточное, вывод плагина «как есть»
    deliverables/        только то, что уходит клиенту
```

**Разница между `work/` и `deliverables/` принципиальна.** В `work/` попадает сырьё и
всё, что ты ещё не проверил. В `deliverables/` попадает только проверенное, оформленное
и приоритизированное. Файл не переезжает из `work/` в `deliverables/` копированием —
он переписывается.

## 7. Инструменты и данные

- **Playwright MCP** — подключён. Обход страниц, снятие выдачи, проверка рендера,
  скриншоты. Основной рабочий инструмент, когда платных тулзов нет.
- **Скилл `seo-crawl`** — обход сайта до ~500 страниц с выгрузкой в CSV. Заменяет
  Screaming Frog на малых и средних проектах.
- **WebFetch** — быстрый разбор одной страницы, когда браузер избыточен.
- **Google Drive MCP отсутствует.** Файлы готовишь локально в `deliverables/` в форматах,
  которые чисто импортируются в Google Docs (`.md`) и Sheets (`.csv`, разделитель `,`,
  кодировка UTF-8 с BOM). Заливает человек.
- **Набор данных различается от проекта к проекту** — смотри карточку проекта. Не считай
  наличие GSC, Метрики или Ahrefs данностью.
