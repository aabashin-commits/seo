Проведи технический SEO-аудит для: **$ARGUMENTS**

## Порядок

1. **Прочитай карточку проекта** `projects/<клиент>/project-profile.md`.
   Нет карточки — заведи по `docs/01-project-onboarding.md`, выяснив недостающее
   одним блоком вопросов.

2. **Собери данные о сайте:**
   - Скилл `seo-crawl` для обхода сайта → `data/crawl-<дата>.csv`
   - Есть выгрузки в `data/` — используй их вместо повторного краула
   - Проверь коды ответа, robots.txt, sitemap.xml, редиректы, мягкий 404

3. **Запусти скиллы плагина** `seo-audit` и `technical-seo`.
   Вывод положи в `work/plugin-audit-<дата>.md` **как есть**, не редактируя.

4. **Пройди общий чек-лист** из `docs/02-tech-audit.md` с пороговыми значениями.

5. **Пройди яндексовый чек-лист** — это то, чего плагин не знает:
   - Региональность: назначен ли регион в Вебмастере, подтверждён ли контентом
   - Яндекс.Вебмастер: Диагностика, Страницы в поиске, причины исключения, ИКС
   - Признаки переоптимизации текстов (риск «Баден-Бадена»)
   - Поведенческие: скорость, первый экран, работоспособность форм и телефонов
   - Остатки разметки Турбо-страниц (отключены Яндексом в апреле 2025) — на удаление
   Результат → `work/yandex-check-<дата>.md`

6. **Коммерческие факторы** (если сайт коммерческий) — сравнение с топ-5 выдачи
   по главному коммерческому запросу в регионе клиента, по `docs/06-commercial-local-links.md`.
   Результат → `work/commercial-<дата>.md`

7. **Сведи три источника**, разреши противоречия, приоритизируй по модели
   «эффект × трудозатраты» с блоком быстрых побед (`docs/07-reporting.md`).

8. **Оформи результат:**
   - `deliverables/audit-<домен>-<дата>.md` по `templates/audit-report.md`
   - `deliverables/task-list-<домен>-<дата>.csv` по `templates/task-list.csv`

## Обязательно

- Каждое число — с источником и датой.
- Пометки `[факт]` / `[оценка]` / `[плагин]` расставлены.
- Каждая задача содержит: что сделать, почему, как проверить, кто делает, сколько часов.
- Формулировки задач адаптированы под CMS клиента (`docs/09-cms-playbooks.md`).
- Вывод плагина не переносится в `deliverables/` копированием — только переписыванием.
- Раздел «Нужны данные» заполнен.

Правки на боевом сайте не вноси. Клиенту ничего не отправляй.
