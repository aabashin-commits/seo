Собери семантическое ядро для: **$ARGUMENTS**

## Порядок

1. **Прочитай карточку проекта.** Критично: регион, тип сайта, ниша, стоп-темы,
   какие платные инструменты доступны.

2. **Сформируй базис** — маркерные запросы словами самого клиента: с сайта, из прайса,
   из описания услуг. 20–60 масок для среднего проекта.

3. **Расширь ядро** по `docs/03-semantics.md`:
   - Wordstat: левая и правая колонки по каждой маске, **регион из карточки**
   - Подсказки поиска и «вместе с этим ищут» — снимай через Playwright
   - Есть Вебмастер/GSC — выгрузи запросы, по которым сайт уже показывается
   - Есть Ahrefs/Keys.so — запросы конкурентов
   - Синонимы и народные формулировки — добавь руками

4. **Сними три частотности** через операторы Wordstat, в разные колонки:
   - `freq_base` — базовая
   - `freq_phrase` — фразовая, `"запрос"`
   - `freq_exact` — точная, `"!запрос !слово"` ← основа приоритизации

5. **Почисти:**
   - Универсальные минус-слова + минус-слова под тип сайта (списки в `docs/03-semantics.md`)
   - Персональные минус-слова: чужие бренды, чужие города, отсутствующие услуги
   - Признак накрутки: базовая высокая, точная около нуля (хуже 1:100) — отбрасывай
   - Запросы, под которые у клиента нет и не будет страницы

6. **Разметь интент:** информационный / коммерческий / транзакционный /
   навигационный / гео. Спорные проверь в выдаче через Playwright — интент
   определяется выдачей, а не словами в запросе.

7. **Выгрузи** в `data/semantic-core.csv` по `templates/semantic-core.csv`:
   UTF-8 с BOM, разделитель `,`, колонки
   `query,freq_base,freq_phrase,freq_exact,region,intent,cluster,target_url,priority,source,checked_at`.
   Колонки `cluster` и `target_url` оставь пустыми — они заполняются в `/relevance-map`.

## Обязательно

- Регион выставлен в Wordstat. Частотность по России для локального бизнеса — брак.
- В колонке `source` указано, откуда взята частотность. Данные Ahrefs и Wordstat
  в одну колонку не смешиваются.
- `checked_at` заполнен у каждой строки.
- Размер ядра соответствует числу страниц, которое клиент реально создаст.
- Числа не выдуманы. Нет доступа к Wordstat — оставь поле пустым и вынеси
  в список «нужны данные», не подставляй правдоподобное.

Итогом отчитайся: сколько запросов собрано, сколько отброшено и по каким причинам,
какая суммарная точная частотность осталась.
