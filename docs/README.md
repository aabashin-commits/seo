# Документация

Подробные методики. `CLAUDE.md` содержит правила и сокращённые сценарии, здесь — детали.
Читай нужный файл в момент, когда взялся за соответствующую задачу, а не все подряд.

| Файл | Когда читать |
|---|---|
| `01-project-onboarding.md` | Новый клиент, заполнение карточки проекта, нехватка данных |
| `02-tech-audit.md` | Технический аудит, индексация, скорость, коды ответа |
| `03-semantics.md` | Сбор ядра, частотности, чистка, минус-слова |
| `04-clustering.md` | Кластеризация, карта релевантности, каннибализация |
| `05-content-onpage.md` | Title/description, ТЗ копирайтеру, LSI, перелинковка |
| `06-commercial-local-links.md` | Коммерческие факторы, Я.Бизнес и Карты, ссылочное |
| `07-reporting.md` | Приоритизация задач, оформление отчёта клиенту |
| `08-searchfit-plugin.md` | Любое обращение к плагину SearchFit |
| `09-cms-playbooks.md` | Определили CMS клиента, нужно понять что реально можно |
| `10-niches.md` | Услуги/локальный бизнес или инфосайт/медиа |
| `11-geo-aeo.md` | Блок AI-видимости в аудите или ТЗ |

## Принцип

Доки описывают **как делать**, а не **что такое SEO**. Если в доке появляется абзац,
объясняющий общеизвестное, — он лишний. Если появляется чек-лист без пороговых
значений — он недоделан.
